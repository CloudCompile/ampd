  what this page does
  
Streams the Tidbyt's serial logs to the tonearm server so the agent can
  read boot output and crash traces remotely, and executes agent-queued ops
  (chip_id, firmware flashes) in this browser via esptool-js — the same
  engine web.esphome.io uses. Keep this tab open with the device plugged in
  whenever the agent needs the wire.
